# iOS QA 시나리오

- 작성일: 2026-03-12
- 대상 프로젝트: `nookipedia-api`
- 목적: iPhone 앱 1차 출시 범위를 기준으로 핵심 회귀 시나리오를 정의한다.

## 1. 기본 로딩

1. 앱 첫 실행 시 홈 화면이 정상 표시된다.
2. 서버 연결 실패 시 오류 화면과 재시도 버튼이 보인다.
3. 앱 재실행 시 마지막 캐시 데이터를 먼저 보여줄 수 있다.

## 2. 홈

1. 홈 요약 데이터가 표시된다.
2. 현재 잡을 수 있는 생물 목록이 정상 표시된다.
3. 홈에서 주민/카탈로그/일정으로 이동이 자연스럽다.

## 3. 주민

1. 이름 검색 결과가 즉시 갱신된다.
2. 성격/종 필터가 정상 동작한다.
3. 좋아하는 주민 상태를 변경하고 재진입 시 유지된다.
4. 우리 섬 주민 10명 초과 시 오류 메시지가 보인다.
5. `on_island=true` 목록에서 정렬 순서가 유지된다.

## 4. 카탈로그 목록

1. 카탈로그 타입 전환 시 다른 목록이 표시된다.
2. 검색/필터/정렬이 정상 동작한다.
3. 첫 페이지 로딩 후 추가 페이지 로딩이 동작한다.
4. 빈 결과에서 빈 상태 문구가 보인다.

## 5. 카탈로그 상세

1. 상세 진입 시 대표 이미지와 상태가 표시된다.
2. 보유/기증/수량 변경이 저장된다.
3. 변형 상태 변경이 저장된다.
4. 상세에서 뒤로 가기 후 목록 상태가 유지된다.

## 6. 섬 프로필/플레이어

1. 섬 프로필 조회/수정이 정상 동작한다.
2. 플레이어 추가/수정/대표 지정이 동작한다.
3. 플레이어 삭제 전 확인 경고가 노출된다.

## 7. 캘린더

1. 월간 일정 조회가 동작한다.
2. 날짜별 일정 목록이 열린다.
3. 일정 추가/수정/체크/삭제가 동작한다.
4. 월 이동 후 주석 데이터가 갱신된다.

## 8. 네트워크 장애

1. 목록 로딩 중 네트워크가 끊겨도 앱이 크래시하지 않는다.
2. 캐시된 화면은 fallback으로 표시된다.
3. 쓰기 실패 시 오류 메시지와 재시도 경로가 제공된다.

## 9. 이미지/성능

1. 빠른 스크롤 중 이미지 깜빡임이 과도하지 않다.
2. placeholder에서 실제 이미지로 자연스럽게 전환된다.
3. 캐시된 화면 재진입 시 체감 속도가 개선된다.

## 10. 접근성

1. 주요 버튼과 토글이 VoiceOver로 읽힌다.
2. 터치 타깃이 충분하다.
3. Dynamic Type에서 레이아웃이 깨지지 않는다.
