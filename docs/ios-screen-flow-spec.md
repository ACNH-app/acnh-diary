# iOS 화면 흐름 명세

- 작성일: 2026-03-12
- 대상 프로젝트: `nookipedia-api`
- 목적: iPhone 앱 1차 범위의 주요 화면 전환과 UX 흐름을 정의한다.

## 1. 전역 구조

하단 탭:

1. 홈
2. 주민
3. 카탈로그
4. 일정
5. 설정

## 2. 홈 흐름

1. 앱 실행
2. 홈 진입
3. 홈 요약 로드
4. 빠른 진입:
- 주민 탭 이동
- 카탈로그 탭 이동
- 일정 탭 이동

## 3. 주민 흐름

1. 주민 탭 진입
2. 기본 목록 표시
3. 검색/필터
4. 셀 탭
5. 주민 상세 또는 액션 시트
6. 상태 변경
7. 목록 복귀

섬 주민 정렬:

1. 주민 탭
2. 우리 섬 주민 필터
3. 편집 모드 진입
4. 순서 변경
5. 저장

## 4. 카탈로그 흐름

1. 카탈로그 탭 진입
2. 카탈로그 타입 선택 또는 기본 타입 노출
3. 목록 로드
4. 검색/필터/정렬 시트 열기
5. 목록 항목 탭
6. 상세 화면 진입
7. 보유/기증/수량/변형 상태 수정
8. 뒤로 가기

## 5. 일정 흐름

1. 일정 탭 진입
2. 월간 캘린더 표시
3. 날짜 선택
4. 일자 상세 시트
5. 일정 추가/수정/체크/삭제
6. 월간 화면 반영

## 6. 설정 흐름

1. 설정 탭 진입
2. 섬 프로필 화면
3. 프로필 편집
4. 플레이어 관리 진입
5. 플레이어 추가/삭제/대표 지정

## 7. 공통 UX 규칙

1. 검색/필터는 화면 전체를 덮지 않고 시트로 우선 제공
2. 상세는 웹 모달 대신 push 화면 우선
3. 삭제는 항상 확인 다이얼로그 제공
4. 저장 실패는 토스트 또는 인라인 에러로 노출
