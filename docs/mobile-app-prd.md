# ACNH 모바일 앱 PRD

- 작성일: 2026-03-12
- 대상 프로젝트: `nookipedia-api`
- 플랫폼: `iOS + Android (Flutter)`

## 1. 제품 정의

Animal Crossing: New Horizons 플레이어가 주민, 카탈로그, 섬 정보와 일정을 모바일에서 빠르게 조회하고 관리할 수 있는 로컬 우선 모바일 앱

## 2. 목표

1. 핵심 상태 수정 플로우를 모바일에서 짧게 만든다.
2. 홈에서 오늘 필요한 정보를 빠르게 보여준다.
3. 공통 코드베이스로 iOS와 Android를 함께 지원한다.
4. 앱 설치 후 네트워크 없이도 핵심 조회/기록 기능이 동작하게 한다.

## 3. 1차 출시 범위

포함:

1. 홈 요약
2. 주민 목록/검색/필터/상태 수정
3. 카탈로그 목록/상세/보유 체크
4. 변형 상태 체크
5. 섬 프로필/플레이어 관리
6. 캘린더 조회/추가/체크/삭제
7. 읽기 캐시
8. 이미지 캐시
9. 로컬 DB 기반 사용자 상태 저장
10. 유료 사용자용 광고 제거

제외:

1. 로그인
2. 소셜 기능
3. 푸시 알림
4. 멀티디바이스 동기화
5. 서버 계정 시스템
6. 구독형 유료 플랜

## 4. 핵심 탭 구조

1. 홈
2. 주민
3. 카탈로그
4. 일정
5. 설정

## 5. 성공 기준

1. 홈, 주민, 카탈로그의 주요 행동을 3탭 이내에 수행
2. 목록과 상세가 모바일에서 자연스럽게 동작
3. 네트워크 없이도 기존 저장 데이터 조회와 수정이 가능
4. 유료 구매 후 광고가 즉시 제거되고 복구가 가능

## 6. 운영 모델

1. 별도 앱 서버 없이 동작한다.
2. 앱 데이터는 디바이스 로컬 DB에 저장한다.
3. 콘텐츠 데이터는 앱 번들 포함 또는 앱 업데이트로 배포한다.
4. 유료 기능은 광고 제거 1종만 제공한다.
5. 결제 검증은 스토어 복구 범위 내에서 처리하고 앱 계정 인증은 두지 않는다.
