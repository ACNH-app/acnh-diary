# 모바일 배포/스토어 계획

- 작성일: 2026-03-12
- 대상 프로젝트: `nookipedia-api`
- 플랫폼: `App Store + Play Store`

## 1. 환경

1. `dev`
2. `prod`

환경별 설정:

1. 앱 이름 suffix
2. 디버그 메뉴 노출 여부
3. 광고 on/off 설정
4. 스토어 결제 상품 ID

## 2. 배포 채널

1. 내부 개발 빌드
2. TestFlight
3. Play Internal Testing
4. 정식 배포 빌드

## 3. 스토어 제출 전 체크

1. 앱 설명/스크린샷 준비
2. 개인정보 처리방침 필요 여부 검토
3. 데이터/이미지 사용 권한 정리
4. 광고 제거 구매 복구 UX 점검
5. 미구현 메뉴 제거

## 4. 공개 배포 전 주의

1. 앱은 로컬 저장 기반이므로 첫 실행 이후 핵심 기능이 네트워크 없이도 동작해야 한다.
2. App Store와 Play Store 모두 비정상 종료 없는 빌드 필요
3. 인앱결제 상품과 광고 SDK 설정이 플랫폼별로 맞아야 한다.

## 5. 수익화 정책

1. 무료 사용자: 광고 표시
2. 유료 사용자: 광고 제거
3. 별도 계정 시스템 없이 스토어 구매 복구만 제공
4. 구독보다 일회성 광고 제거 구매를 우선 검토
