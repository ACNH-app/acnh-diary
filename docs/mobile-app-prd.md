# ACNH 모바일 앱 PRD

- 작성일: 2026-03-12
- 대상 프로젝트: `nookipedia-api`
- 플랫폼: `iOS + Android (Flutter)`

## 1. 제품 정의

Animal Crossing: New Horizons 플레이어가 주민, 카탈로그, 섬 정보와 일정을 모바일에서 빠르게 조회하고 관리할 수 있는 앱

## 2. 목표

1. 핵심 상태 수정 플로우를 모바일에서 짧게 만든다.
2. 홈에서 오늘 필요한 정보를 빠르게 보여준다.
3. 공통 코드베이스로 iOS와 Android를 함께 지원한다.

## 3. 1차 출시 범위

포함:

1. 홈 요약
2. 주민 목록/검색/필터/상태 수정
3. 카탈로그 목록/상세/보유 체크
4. 변형 상태 체크
5. 섬 프로필/플레이어 관리
6. 캘린더 조회/추가/체크/삭제
7. 읽기 캐시
8. 이미지 캐시

제외:

1. 로그인
2. 소셜 기능
3. 푸시 알림

## 4. 핵심 탭 구조

1. 홈
2. 주민
3. 카탈로그
4. 일정
5. 설정

## 5. 성공 기준

1. 홈, 주민, 카탈로그의 주요 행동을 3탭 이내에 수행
2. 목록과 상세가 모바일에서 자연스럽게 동작
3. 네트워크 실패 시 캐시 fallback 제공
