# Flutter 유료/광고 정책 설계

- 작성일: 2026-03-12
- 대상 프로젝트: `nookipedia-api`

## 1. 목표

1. 무료 사용자에게만 광고를 노출한다.
2. 유료 사용자는 광고 제거만 제공한다.
3. 계정 시스템 없이 단순한 수익화 구조를 유지한다.

## 2. 상품 정책

1. 상품 종류: 일회성 `광고 제거`
2. 플랜 수: 1개
3. 유료 사용자 추가 기능: 없음

## 3. Entitlement 모델

1. `free`
2. `ad_free`

## 4. 결제 흐름

1. 사용자가 광고 제거 구매 버튼 탭
2. 스토어 결제 시도
3. 성공 시 `ad_free` 활성화
4. 앱 재시작 시 entitlement 캐시 확인
5. 사용자가 원할 때 구매 복구 실행

## 5. 광고 노출 정책

1. 홈 피드 하단
2. 카탈로그 목록 중간
3. 설정 화면에는 광고 미노출
4. 유료 사용자는 모든 광고 슬롯 비활성화

## 6. 저장 정책

1. entitlement 상태는 일반 설정과 분리 저장
2. 광고 제거 여부는 앱 시작 직후 로드
3. 복구 실패 시 기존 캐시 상태를 유지하되 설정에서 재시도 가능

## 7. 사용자 안내

1. 로그인 없이 광고 제거 구매가 가능하다고 명시
2. 앱 삭제/재설치 시 스토어 복구 버튼 제공
3. 다른 기기 자동 동기화는 보장하지 않는다고 명시

## 8. 기술 구성

1. `PurchaseService`
2. `PremiumStateProvider`
3. `AdsService`
4. `AdVisibilityPolicy`

## 9. QA 포인트

1. 구매 성공 후 광고 즉시 제거
2. 구매 복구 성공
3. 구매 취소/실패 처리
4. 광고 SDK 실패 시 앱 기능 유지
