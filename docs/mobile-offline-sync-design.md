# 모바일 오프라인/동기화 설계

- 작성일: 2026-03-12
- 대상 프로젝트: `nookipedia-api`

## 1. 1차 목표

1. 읽기 캐시 제공
2. 마지막 성공 데이터 fallback
3. 쓰기 오프라인 지원은 제한적으로 검토

## 2. 캐시 대상

1. 홈 마지막 응답
2. 주민 기본 목록
3. 카탈로그 타입별 첫 페이지
4. 최근 본 상세
5. 메타 데이터

## 3. 쓰기 큐 후보

1. 주민 상태 변경
2. 카탈로그 보유/변형 상태 변경
3. 캘린더 체크/추가/삭제

제외 권장:

1. 플레이어 삭제
2. 섬 주민 순서 재정렬

## 4. 큐 규칙

1. FIFO 재전송
2. 같은 리소스 최신 변경으로 압축 가능
3. 4xx는 실패 종료
4. 네트워크 오류/5xx는 재시도
